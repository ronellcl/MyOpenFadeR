MyOpenFadeR packages

APT and pacman repositories for MyOpenFadeR 0.5.6. The packages install the app in /opt/myopenfader, add openfader to the PATH and a desktop menu entry.

Debian / Ubuntu

echo 'deb [trusted=yes] https://ronellcl.github.io/MyOpenFadeR/debian stable main' | sudo tee /etc/apt/sources.list.d/myopenfader.list
sudo apt update
sudo apt install myopenfader

Arch Linux / CachyOS

Add these lines to /etc/pacman.conf:

[myopenfader]
SigLevel = Optional TrustAll
Server = https://ronellcl.github.io/MyOpenFadeR/arch/x86_64

Then:

sudo pacman -Sy myopenfader

Portable archive

The .tar.gz archive is published with each release at github.com/ronellcl/MyOpenFadeR/releases.
